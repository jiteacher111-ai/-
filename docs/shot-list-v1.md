## 공통 움직임 제한

- 일반 이동은 최소 12프레임 이상 보간한다.
- `spring` 사용 시 과한 튕김을 피하고 damping 18 이상을 기본값으로 한다.
- 캐릭터 회전은 일반 장면 ±3도, 달리기 장면 ±6도 이내로 제한한다.
- 카메라 줌은 한 숏에서 8%를 넘지 않는다.
- 그네는 최대 ±6도만 움직이고 장면 후반에 반드시 완전히 정지한다.
- 잘못된 행동은 5초 이내로 끝내고 올바른 행동을 더 오래 보여준다.
