1Gemini CLI 설치

터미널에서 제미나이를 부릅니다

$ npm install -g @google/gemini-cli
$ gemini
# 처음 실행 → "Google 계정으로 로그인" 선택

구글 계정으로 로그인하면 무료 사용량 안에서 바로 쓸 수 있습니다.

2HyperFrames 확장 설치

제미나이에게 영상 만드는 법을 가르치기

$ gemini extensions install \
  https://github.com/heygen-com/hyperframes \
  --auto-update
$ gemini extensions list # 설치 확인

설치 후 Gemini CLI를 다시 시작해야 스킬이 적용됩니다.

3영상 프로젝트 만들기

영상 한 편 = 폴더 하나

$ npx hyperframes init my-video
$ cd my-video
$ gemini

index.html(영상 본체)과 설정 파일이 자동으로 생깁니다.
