1대본 쓰기 · Google AI Studio

Playground에서 Flash 모델로 30초 대본

프롬프트 예시 달 모양이 왜 바뀌는지 초등학생과 중학생에게 알려 주는 모션그래픽 영상을 만들려고 합니다. 30초 가량의 대본을 작성해 주세요.
  • 모델은 무료 Flash (최신 유료 전용 모델은 선택 X)
  • Enter는 줄 바꿈, 실행은 Ctrl + Enter → 나레이션 대사만 메모장에 복사
2감정 담은 나레이션 · AI Studio TTS

글자를 목소리로 바꾸기 (Text-to-Speech)

  • 모델을 Flash TTS로 바꾸고 새 대화(Create new dialog)
  • 대본을 붙여 넣고 목소리(스피커) 고르기
핵심: 감정 · 분위기 칸 "밝은 나레이션 톤" 추천 프롬프트를 붙여 넣기 → 실행 → 다운로드
3SRT 자막 파일 · AI Studio Flash

몇 초에 무슨 말을 하는지 알려 주기

  • 모델을 다시 Flash로
  • 방금 받은 나레이션 음성 파일을 첨부
  • "SRT 파일로 만들어 줘" → 실행 → 다운로드

무료 버전에서 꼭 필요한 파일: Claude가 자막 시간에 맞춰 화면을 바꿉니다.

4배경음악 · Gemini 앱

+ → 음악 만들기 (짧게 · 보컬 없음)

프롬프트 예시 '달의 모양은 왜 바뀔까?'라는 주제로 모션그래픽 영상에 사용할 배경 음악입니다.

완성되면 커버 이미지는 빼고 음악(오디오)만 다운로드

AI Studio의 음악 만들기는 이제 유료 전용 → 음악은 Gemini 앱에서 무료로

5실행 전 설정 · Claude

외부 네트워크 접속 허용을 켜세요

  • 사이드바 → 계정 클릭 → 설정
  • 기능 메뉴 → 외부 네트워크 접속 허용 켜기 (기본은 꺼짐)

무료 사용자는 기본 모델 Sonnet 그대로 OK · 켜야 웹의 외부 소스(폰트 등)를 받아 작업

6모션그래픽 만들기 · Claude

파일 3개 + 프롬프트 = 끝

  • 채팅창에 나레이션 · SRT 자막 · 배경음악 첨부
  • 준비한 프롬프트를 붙여 넣고 주제만 바꾸기
  • 녹화 모드 버튼도 만들어 달라고 요청
스타일 칸 "스타일은 네가 할 수 있는 걸로 잘 만들어 줘. 너한테 위임할게."
7HTML로 내보내기

결과물은 영상이 아니라 웹페이지

  • 공유 → 내보내기 → HTML 페이지 받기
  • 카카오톡 · 구글 드라이브에 올려 두고 필요할 때 열기
  • F11 전체 화면 → 녹화 모드로 재생 = 파워포인트처럼
8MP4로 만들기 · 윈도우 기본 도구

화면 녹화 → Clipchamp로 다듬기

  • Win + Shift + R 캡처 도구 녹화 → 화면 전체 드래그 → 시작
  • HTML을 F11 전체 화면 + 녹화 모드로 재생 → 중지
  • 캡처 도구 오른쪽 위 Clipchamp → 앞뒤 자르기 → 내보내기

💡 녹화 전에 마우스 커서는 화면 밖으로 숨기기

예제 2회사 매출 발표 영상

엑셀 데이터로 만드는 9월 매출 보고

  • 엑셀 범위 복사 → Ctrl + Shift + V (값으로 붙여 넣기)
  • 나레이션은 "힘 있는 나레이션 톤" · 음악은 발표용 팝 연주곡
  • Claude 프롬프트의 데이터 칸에 매출 데이터 넣기
스타일 칸 "커피 매장 느낌의 다크브라운 강조색을 활용한 기업 IR 프레젠테이션 스타일"
예제 3복스(Vox) 스타일 커플 이야기

사진 스티커가 움직이는 결혼 스토리

  • AI Studio 이미지 모델 나노 바나나 무료(라이트)로 장면 그림 만들기
  • 무료는 투명 배경이 잘 안 됨 → 크로마키 녹색 배경으로 생성 (끊기면 "계속 생성")
  • Claude에게: "초록 배경을 지우고 흰 테두리 스티커로 붙여 줘"

대본 → 밝은 톤 나레이션 → SRT → 음악 과정은 똑같습니다.
